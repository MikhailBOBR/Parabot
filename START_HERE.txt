ПАРАБОТ — С ЧЕГО НАЧАТЬ

1. Распакуйте весь архив в папку на компьютере.
2. Установите Python 3.11+ с python.org, включите Add Python to PATH.
3. В Telegram создайте бота: @BotFather → /newbot. Скопируйте токен.
4. На Windows дважды нажмите start.bat. Откроется .env:
   BOT_TOKEN=сюда_токен
   ADMIN_IDS=сюда_ваш_числовой_ID
   Если ID неизвестен, временно оставьте поле пустым. После запуска
   напишите вашему боту /id в личку, вставьте ID и перезапустите.
5. Добавьте бота в группу и назначьте администратором.
6. В нужной теме отправьте /setup. Нажмите «Настроить в личке».
7. Выберите людей галочками или внесите @теги вручную.
8. Нажмите «Ввести пары» и отправьте, например:
   Пн | 09:00-10:30 | Математика | 304
   Вт | 12:40-14:10 | Английский
9. Подтвердите сохранение. Нажмите «Опубликовать кнопку».

ОТМЕНЫ И ПЕРЕНОСЫ
В личке: /admin → группа → «Отмены и переносы» → нужная дата.
- Нажмите пару → «Отменить эту пару»: только на выбранную дату.
- «Отменить все пары на день» → подтвердить: отменить весь день.
- Нажмите пару → «Перенести / изменить время» → отправьте:
  2026-10-06 | 11:00-12:30 | 201
  Или только 11:00-12:30, чтобы оставить ту же дату и аудиторию.
  Проверьте «Было / Будет» и нажмите «Сохранить».
- «Вернуть исходную пару» и «Восстановить день» отменяют изменения.
- «Изменить постоянное расписание»: изменить пару на все недели.
Отмена работает сразу, без перезапуска. Уже отправленное напоминание
остаётся в группе. Следующие недели после разовой отмены сохраняются.

ЧЁТНАЯ И НЕЧЁТНАЯ НЕДЕЛЯ
/admin → группа → «Чётная / нечётная неделя».
1. Укажите «Эта неделя чётная» или «Эта неделя нечётная» по вузу.
2. «Чётная неделя» → «Ввести расписание» → отправьте пары → сохраните.
3. «Нечётная неделя» → «Ввести расписание» → отправьте пары → сохраните.
Не нужно писать чётность в каждой строке: выбрана для всего ввода.
Бот сам переключает недели каждый понедельник, без ручного включения.
Пары «Каждую неделю» действуют на обеих неделях. Старые записи без
чётности остаются общими: измените/удалите их, если они больше не нужны.
Примеры: examples/schedule_even.txt и examples/schedule_odd.txt.

РАСПИСАНИЕ НА ЗАВТРА ПО ТАЙМЕРУ
/admin → группа → «Расписание на завтра» → «Выбрать время».
Отправьте 23:30 или другое время ЧЧ:ММ. После сохранения рассылка
включится: каждый день в это время придёт расписание следующего дня
в настроенную тему. Время — по часовому поясу группы.
Чётность недели, отмены и переносы учитываются автоматически.
«Предпросмотр на завтра» показывает текст только вам в личке.
«Выключить рассылку» останавливает её, сохраняя выбранное время.
По умолчанию опция выключена; напоминания перед парой и /ping
управляются отдельно. Бот должен работать в выбранное время.

Группа получает сообщения в выбранной теме. Первый вызов через
«Отмечаемся» или /ping запускает общий отдых на 5 минут для всех.
Повторные нажатия не продлевают этот таймер; перезапуск не сбрасывает.

На обычном компьютере бот работает, пока окно запуска открыто,
компьютер включён и есть интернет. Для круглосуточной работы
запустите на постоянно работающем сервере; Docker включён в архив.

Бот не может выгрузить весь состав Telegram-группы. Знакомьте
людей с ботом через /join или кнопку «Я участник»; либо добавляйте
@теги / командой /add ответом на сообщение. Новых обнаруженных
людей в режиме «только выбранные» включает администратор.

Подробности, команды и ответы на вопросы — в README.md.
