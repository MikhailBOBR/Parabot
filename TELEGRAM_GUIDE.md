# Как подключить ПараБота к Telegram и управлять им

Всё управление расписанием происходит в личной переписке с ботом. В группе бот показывает расписание и отправляет напоминания выбранным людям. По умолчанию — за 5 минут до начала пары.

## 1. Создать бота в Telegram

1. Откройте [@BotFather](https://t.me/BotFather) и нажмите **Start**.
2. Отправьте `/newbot`.
3. Введите название, например `ПараБот нашей группы`.
4. Придумайте свободный username, заканчивающийся на `bot`, например `our_group_para_bot`.
5. BotFather выдаст токен вида `123456789:ABC...`. Сохраните его: он понадобится для запуска. Токен даёт доступ к боту, поэтому не публикуйте его и не отправляйте в группу.

Создание через BotFather описано в [официальной инструкции Telegram](https://core.telegram.org/bots/features#creating-a-new-bot).

## 2. Запустить на Windows

1. Установите Python **3.11 или новее** с [python.org](https://www.python.org/downloads/windows/). При установке отметьте **Add Python to PATH**.
2. Откройте папку проекта `C:\BOT_otmechalovo\Parabot`.
3. Дважды нажмите **start.bat**. Скрипт подготовит окружение, установит зависимости и при первом запуске откроет файл `.env`.
4. Вставьте токен после `BOT_TOKEN=`. Пока не знаете свой ID, оставьте `ADMIN_IDS=` пустым. Сохраните файл, закройте Блокнот и продолжите запуск в окне скрипта.
5. Откройте своего нового бота в Telegram и отправьте ему `/id` **в личку**. Он ответит вашим числовым ID.
6. Остановите программу через **Ctrl+C**. Откройте `.env` и заполните `ADMIN_IDS` полученным числом:

   ```dotenv
   BOT_TOKEN=ваш_настоящий_токен_из_BotFather
   ADMIN_IDS=123456789
   TIMEZONE=Europe/Moscow
   DB_PATH=data/parabot.sqlite3
   ```

   Это образец: токен и ID замените своими. Кавычки не нужны.

7. Сохраните файл и снова запустите **start.bat**.

Пока `ADMIN_IDS` пуст, бот отвечает на `/id`, но управление закрыто. Для нескольких доверенных администраторов перечислите их ID через запятую: `ADMIN_IDS=123456789,987654321`, затем перезапустите программу. Обычный статус администратора Telegram-группы сам по себе не открывает настройки: ваш ID должен быть в этом списке. Для первого подключения группы вы также должны быть её администратором.

## 3. Подключить группу и тему

1. Добавьте бота в учебную группу и назначьте **администратором**. Ему нужна возможность писать в выбранную тему. Права удалять сообщения, блокировать людей или управлять темами для работы ПараБота не нужны.
2. Если в группе есть темы, откройте тему для напоминаний. Если тем нет, используйте общий чат.
3. Отправьте в ней `/setup`. При нескольких ботах можно указать адресата: `/setup@username_вашего_бота`.
4. Нажмите **«Настроить в личке»**. Если Telegram попросит — нажмите **Start**.

Дальше настройки доступны через `/admin` в личке: выберите нужную группу. Повторный `/setup` сохраняет существующие пары и получателей.

Чтобы позже сменить тему, откройте новую тему и отправьте `/topic`, затем `/panel`.

## 4. Выбрать получателей

В личном меню нажмите **«Выбрать людей»** и включите нужные имена галочками. Чтобы люди появились в списке, используйте любой способ:

- Попросите участников написать `/join` в группе или нажать **«Я участник»** на панели.
- Нажмите **«@теги»** и отправьте `@student_one @student_two`. Введённые теги сразу выбраны.
- В группе отправьте `/add` ответом на сообщение нужного человека. Он сразу попадёт в получатели; username для этого не требуется.

По умолчанию бот зовёт **только выбранных**. Кнопка **«Режим получателей»** позволяет включить всех известных боту людей. Telegram не предоставляет ботам полный список участников, поэтому для регистрации удобнее `/join`. Администратор бота получает сообщения группы без дополнительного отключения Privacy Mode; ограничения описаны в [Telegram FAQ](https://core.telegram.org/bots/faq#what-messages-will-my-bot-get).

## 5. Внести расписание

Нажмите **«Ввести пары»** и отправьте, например:

```text
Пн | 09:00-10:30 | Математика | 304
Пн | 10:40-12:10 | Физика | 201
Вт | 12:40-14:10 | Английский
2026-10-05 | 15:00-16:30 | Консультация | Онлайн
```

Бот покажет предпросмотр. Нажмите **«Сохранить»**, затем в меню **«Опубликовать кнопку»**. В группе появится панель с кнопками **«Отмечаемся»**, **«Сегодня»**, **«Я участник»**. При желании закрепите панель средствами Telegram.

День недели задаёт повторяющуюся пару, конкретная дата — разовую. Аудитория необязательна. Дополнительное пятое поле `четная` или `нечетная` задаёт, на какой неделе проходит пара. Чётность настраивается в меню ниже. Время считается по часовому поясу группы; для Москвы оставьте `Europe/Moscow`.

## Два расписания: чётная и нечётная неделя

В личке откройте **`/admin` → группа → «Чётная / нечётная неделя»**.

1. Если вуз использует своё чередование, нажмите **«Эта неделя чётная»** или **«Эта неделя нечётная»**. В меню указана дата понедельника, к которому относится настройка. Достаточно указать её один раз: дальше бот сам меняет чётность каждый понедельник по часовому поясу группы, включая переход через Новый год. На каникулах чередование продолжается; при необходимости поправьте текущую неделю теми же кнопками.
2. Откройте **«Чётная неделя» → «Ввести расписание»**, отправьте все пары этой недели и подтвердите сохранение:

   ```text
   Пн | 09:00-10:30 | Математика | 304
   Вт | 11:00-12:30 | Физика | 201
   ```

3. Откройте **«Нечётная неделя» → «Ввести расписание»**, отправьте другое расписание и сохраните:

   ```text
   Пн | 09:00-10:30 | Информатика | 210
   Ср | 11:00-12:30 | История | 101
   ```

Поле чётности в каждой строке писать не нужно: выбранная неделя применяется ко всему вводу. Для CSV используйте кнопку **«CSV» внутри нужной недели**; колонка `week` необязательна. Если в строке явно указана противоположная чётность, бот попросит исправить её. Конкретные даты добавляйте обычной кнопкой **«Ввести пары»**.

Пары, которые одинаковы каждую неделю, добавляйте в раздел **«Каждую неделю»**. Они действуют вместе с расписанием активной недели. Уже существующие обычные пары без чётности тоже считаются общими; если вместо них теперь два расписания, удалите или измените старые записи через меню, чтобы они не добавлялись к обоим.

В меню и в `/today` видно, какая неделя сейчас. Напоминания и расписание на дату автоматически используют нужный вариант. `/schedule` показывает оба шаблона. Для редактирования и удаления записи в кнопке указан её тип недели, поэтому одинаковые предметы можно различить.

Если учебное чередование не настроено, сохраняется исходный режим **по календарному номеру недели ISO**. Кнопка **«Считать по календарю ISO»** возвращает этот режим после учебной настройки. В календаре могут идти подряд неделя 53 и неделя 1 — обе нечётные; учебное чередование по заданной вами неделе меняется строго через 7 дней.

Примеры для копирования: `examples/schedule_even.txt` и `examples/schedule_odd.txt`. Настройка чередования хранится в базе; CSV сохраняет типы пар, но не выбранную точку отсчёта. При переносе только CSV в новую группу задайте текущую неделю снова.

## 6. Отменить одну пару, в том числе перед самым началом

Путь в личке: **`/admin` → группа → «Отмены и переносы» → «Сегодня» / нужная дата → пара → «Отменить эту пару»**.

Отмена сохраняется сразу, перезапуск не нужен. Бот перестаёт отправлять автонапоминание для этой пары. В `/today` она будет показана с пометкой **«Отменена»**. На следующей неделе обычная еженедельная пара остаётся.

Например, пара начинается в 09:00, напоминание запланировано на 08:55. Если отменить её до начала отправки, напоминания не будет. Отменить можно и позже, но уже отправленное сообщение останется в группе: отмена не удаляет его и не рассылает отдельное объявление. Поэтому при поздней отмене сообщите группе об этом обычным сообщением.

Чтобы вернуть пару, откройте её снова и нажмите **«Вернуть исходную пару»**. Если напоминание уже было отправлено, восстановление не дублирует его. Для перенесённой пары эта кнопка также возвращает первоначальные дату, время и аудиторию.

## 7. Отменить все пары на день

Путь: **`/admin` → группа → «Отмены и переносы» → дата → «Отменить все пары на день» → подтвердить**.

Можно выбрать **сегодня**, **завтра**, день из ближайшей недели или **«Другая дата»** и отправить `2026-10-05` либо `05.10.2026`.

Бот покажет в расписании, что весь день отменён, и остановит автонапоминания для всех пар на эту дату, включая перенесённые туда занятия. Отмена действует только на эту календарную дату и сохраняется после перезапуска. Пары, которые уже перенесли с этой даты на другой день, остаются на новом дне.

Чтобы вернуть занятия, выберите ту же дату и нажмите **«Восстановить день»**. Отдельные отмены и переносы сохранятся — при необходимости восстановите конкретную пару отдельно. Перенести пару на отменённый день можно после его восстановления.

## 8. Перенести пару или подвинуть время

Путь: **`/admin` → группа → «Отмены и переносы» → дата → пара → «Перенести / изменить время»**.

Отправьте новую дату и время:

```text
2026-10-06 | 11:00-12:30
```

Аудитория сохранится. Чтобы поменять её вместе со временем:

```text
2026-10-06 | 11:00-12:30 | 201
```

Чтобы подвинуть только время на том же дне:

```text
11:00-12:30
```

Проверьте **«Было / Будет»** и нажмите **«Сохранить»**. Изменится только выбранное занятие на выбранную дату. Бот покажет перенос в `/today`; пару можно найти и на исходном, и на новом дне в админском меню. Напоминание придёт перед новым временем. Если до нового начала осталось меньше настроенных 5 минут, бот отправит его при ближайшей проверке, обычно в течение 15 секунд, пока пара ещё не началась. При переносе после уже отправленного напоминания бот сможет напомнить заново перед новым временем.

Новое начало должно быть в будущем, конец — позже начала в пределах того же дня. Для перестановки двух пар поменяйте время каждой по очереди. Бот допускает совпадение времён, поэтому проверяйте итоговое расписание сами.

## 9. Изменить постоянное расписание

Если пара теперь каждую неделю проходит в другое время, нажмите **«Изменить постоянное расписание»**, выберите запись и отправьте одну полную строку:

```text
Пн | 10:00-11:30 | Математика | 202 | каждая
```

Подтвердите предпросмотр. Можно изменить день, время, название, аудиторию и чётность недели. Еженедельная запись изменится на все недели; ранее созданные отмены и переносы на конкретные даты сохранятся. Уже отправленное напоминание для той же исходной даты автоматически не повторится: если нужен повтор перед новым временем сегодня, используйте перенос на дату.

**«Удалить пару»** убирает запись и её отдельные изменения из расписания. Для разовой отмены удобнее **«Отмены и переносы»**. **«Очистить расписание»** удаляет все записи; общие отмены календарных дней сохраняются до их восстановления.

## Ежедневная отправка расписания на завтра

В личке откройте **`/admin` → группа → «Расписание на завтра»**.

1. Нажмите **«Выбрать время»**.
2. Отправьте `23:30` или другое время в формате `ЧЧ:ММ` от `00:00` до `23:59`.
3. После сохранения рассылка включится. Каждый день в выбранное время бот отправит расписание **следующего календарного дня** в настроенную тему группы. Например, в понедельник в 23:30 придёт расписание на вторник.

Время считается по часовому поясу группы — для Москвы `Europe/Moscow`. Время по умолчанию — **23:30**, сама рассылка изначально выключена. Можно включить её сразу кнопкой **«Включить рассылку»**, сохранив это время.

Бот берёт расписание на момент отправки: правильную чётную / нечётную неделю, общие и разовые пары, переносы и отмены. В воскресенье он покажет понедельник уже по чётности новой недели. Если на завтра нет пар или весь день отменён, придёт сообщение об этом. Если отключены только напоминания на завтра, расписание всё равно придёт с соответствующей пометкой.

**«Предпросмотр на завтра»** показывает текст только вам в личке. Предпросмотр не отправляет сообщения в группу и не влияет на ежедневную отправку. Это общее сообщение в теме группы; выбор получателей и @тегов для него не требуется.

Чтобы остановить рассылку, нажмите **«Выключить рассылку»**. Выбранное время сохранится. Эта опция управляется отдельно от **«Паузы»** напоминаний перед парой и не меняет пятиминутный таймер `/ping`.

Настройка и отметка отправки сохраняются в базе. Обычный перезапуск, выключение / включение опции или изменение времени после отправки не создают повторное сообщение на ту же дату. Длинное расписание разделяется на несколько сообщений без обрезки пар.

Бот должен работать в выбранное время. Проверка идёт каждые 15 секунд; при короткой задержке допускается отправка в пределах 90 секунд после заданного времени и до смены календарного дня. После более долгого простоя пропущенная рассылка не догоняется — следующая придёт по обычному расписанию. Уже отправленный текст отражает состояние на момент отправки; более поздние изменения смотрите в `/today` и админском меню. При неоднозначном сбое связи автоматического повтора нет, чтобы не дублировать сообщения.

## 10. Остальное управление

| Действие | Где и что делает |
| --- | --- |
| «За сколько минут» | Личное меню: от 1 до 60 минут, по умолчанию 5. |
| «Пауза» | Останавливает напоминания перед парой до ручного включения; рассылка на завтра управляется отдельно. |
| «Расписание на завтра» | Ежедневная отправка в выбранное время, включение / выключение и предпросмотр. |
| «Сегодня без напоминаний» | Отключает только напоминания на сегодня; занятия остаются в расписании. |
| «Отменить все пары на день» | Отмечает выбранную дату как день без занятий. |
| `/today` или «Сегодня» | В группе показывает сегодняшнее расписание с отменами и переносами. |
| `/schedule` | Показывает постоянное расписание; изменения на дату смотрите в `/today` или админском меню. |
| «Отмечаемся» или `/ping` | Первый вызов зовёт выбранных людей; затем общая блокировка на 5 минут для всех участников группы. |
| `/cancel` | Отменяет незавершённый ввод и предпросмотр. |
| «Выгрузить CSV» | Сохраняет постоянное расписание; отмены и переносы на дату в CSV не входят. |

Пауза, отмена пары и отмена дня останавливают автонапоминания. Ручная кнопка **«Отмечаемся»** остаётся доступной по своей обычной пятиминутной блокировке.

У `/ping` и всех кнопок группы один таймер. Например, первый человек позвал в 09:00 — следующий вызов разрешён в 09:05 для любого участника. Повторные попытки в 09:01 или 09:04 не отправляют новый вызов и не продлевают таймер. Старые панели и перезапуск программы также не обходят паузу. У каждой подключённой группы свой таймер.

## 11. Чтобы бот работал постоянно

На вашем компьютере бот работает, пока программа запущена, компьютер включён, не спит и подключён к интернету. Закрытие окна останавливает бота. Запускайте один экземпляр: второй с тем же токеном вызовет `Conflict`.

При кратковременном обрыве связи бот автоматически повторяет подключение. Для long polling увеличен сетевой таймаут, а start.bat повторно запускает процесс после неожиданного сбоя с паузой 10 секунд. Ошибки настройки или токена останавливают запуск и показываются в окне; исправьте .env и запустите start.bat снова. Остановить штатно можно через Ctrl+C.


Для круглосуточной работы используйте постоянно включённый компьютер или сервер. В проекте есть Docker:

```text
docker compose up -d --build
docker compose logs -f --tail=50
```

Перед этим заполните `.env` на сервере. Контейнер перезапускается автоматически и хранит данные в постоянном томе. Не запускайте одновременно локальный бот с тем же токеном. Подробности остановки и обновления — в `README.md`.

Для обновления уже работающего локального бота: остановите его через Ctrl+C, сохраните `.env` и папку `data`, обновите исходники и снова запустите `start.bat`. Новые таблицы создадутся автоматически; существующие настройки, люди и расписание сохранятся.

Для полной резервной копии остановите локального бота и скопируйте `.env` вместе с папкой `data` в безопасное место. База содержит расписание, отмены, переносы, получателей и настройки. CSV для полной резервной копии недостаточно.

## Если что-то не получилось

- **Нет доступа к настройкам:** проверьте свой числовой ID в `ADMIN_IDS` и перезапустите бота. Пишите от личного аккаунта.
- **Нет напоминаний:** проверьте, что программа работает, есть получатели, автонапоминания включены, день и пара не отменены, часовой пояс верный, тема открыта.
- **Нет расписания на завтра:** проверьте, что рассылка включена в её отдельном меню, время и часовой пояс верные, программа работала в это время, тема открыта. Список выбранных людей для этой рассылки не требуется.
- **Подтверждение устарело:** откройте пару заново. Это защита от сохранения старого предпросмотра после отмены ввода или другого изменения.
- **Telegram отклонил отправку:** проверьте права бота и выбранную тему. Ошибка появится в окне программы.
- **Старая пара напомнила до отмены:** уже отправленное сообщение сохраняется. Последующие автонапоминания отменённой пары не отправляются.

Локальные проверки используют имитацию Telegram API. Для реальной работы нужно создать своего бота и выполнить подключение выше.
